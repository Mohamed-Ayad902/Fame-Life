# Backdrop

- Library: `io.github.kyant0:backdrop` 2.0.1 (Compose Multiplatform)
- Source: https://github.com/Kyant0/AndroidLiquidGlass, docs https://kyant.gitbook.io/backdrop
- License: Apache License 2.0 (https://www.apache.org/licenses/LICENSE-2.0)
- Used for: the backdrop blur behind the pinned Home HUD and the tab bar glass. Blur needs Android 12+; on older
  versions the HUD draws a near-opaque tint instead.
